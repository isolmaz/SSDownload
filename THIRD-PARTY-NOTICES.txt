Optional media executables (downloaded separately, not bundled)
---------------------------------------------------------------
SSDownload can install the following upstream executables into the current
user's application-data directory. They are separate programs, are not linked
into SSDownload, and are not included in the installer or portable ZIP.

  yt-dlp
    Project/source: https://github.com/yt-dlp/yt-dlp
    Release API: https://api.github.com/repos/yt-dlp/yt-dlp/releases/latest
    Selected assets: yt-dlp.exe and SHA2-256SUMS from that stable release
    License: The Unlicense

  Deno
    Project/source: https://github.com/denoland/deno
    Release API: https://api.github.com/repos/denoland/deno/releases/latest
    Selected assets: deno-x86_64-pc-windows-msvc.zip and its .sha256sum
    License: MIT

  FFmpeg / ffprobe
    Upstream source: https://ffmpeg.org/ and https://github.com/FFmpeg/FFmpeg
    Windows build provider: https://github.com/BtbN/FFmpeg-Builds
    Release API: https://api.github.com/repos/BtbN/FFmpeg-Builds/releases/latest
    Selected asset: ffmpeg-master-latest-win64-lgpl-shared.zip
    Checksums: checksums.sha256 from that BtbN release
    License: LGPL-3.0-or-later for the selected version-3 LGPL build. SSDownload's installer
    rejects GPL-named build assets and does not describe GPL-enabled FFmpeg as
    permissively licensed. Exact release IDs/tags, URLs, SHA-256 values, versions,
    and license identifiers are saved in the local current.json provenance record.
    FFmpeg source and compliance information: https://ffmpeg.org/legal.html

Each optional tool retains its own copyright and license. Before redistributing a
downloaded tool, consult the license files shipped by its exact upstream release.
SSDownload records tool provenance locally and does not present these tools as
SSDownload-authored software.
